# ModVault 🛡️

**ModVault** is a modern, lightweight desktop Mod Manager built with C# and WPF (.NET 8/9).

The goal of this project is to provide a clean and straightforward way to scan, manage, enable, and disable game mods without permanent file loss.

---

## 🛠️ Tech Stack & Learning Journey

* **Language:** C# 12/13
* **Framework:** WPF (.NET 8 / .NET 9)
* **Architecture:** Modular separation (Models / Services / UI)
* **IDE:** Visual Studio Community 2026

> 💡 **Note on Development:**  
> This project is a hands-on learning exercise. As a beginner in C# and WPF desktop architecture, I am building **ModVault** step-by-step with heavy guidance and mentorship from Gemini (AI).

---

## ✨ Features (Work in Progress)

- [x] Directory scanning for installed mods
- [x] Toggle mods on/off using safe `.disabled` folder renaming
- [ ] Support for single-file plugins (`.asi`, `.dll`, `.pak`)
- [ ] Game directory persistence and profile management
- [ ] Virtual file system / Symlink deployment for clean game installations
